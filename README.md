# Dhyanchand

A modern agricultural services website built with React, TanStack Start, Vite, and Tailwind CSS. The site presents plantation management, export support, irrigation planning, solar power integration, and farm operations for estate owners and international buyers.

## Features

- Responsive React + Tailwind UI
- TanStack Start routing and page handling
- Agricultural service pages and inquiry flows
- Export-focused business presentation
- Cloudflare-compatible Vite setup

## Requirements

- Node.js 20 or later
- npm 10 or later
- Optional: Bun if you prefer, but the project is configured using npm

## Install

Open a terminal in the project folder and run:

```bash
npm install
```

## Start the website locally

```bash
npm run dev
```

Then open the site in your browser at:

```text
http://localhost:8080/
```

## Build for production

```bash
npm run build
```

## Preview the production build locally

```bash
npm run preview
```

This project uses Vite with the `@lovable.dev/vite-tanstack-config` preset, and includes support for Cloudflare worker deployment via `wrangler.jsonc`.
